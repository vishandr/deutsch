# Deutsch — тренажёр слов

Офлайн-приложение (PWA) для iPhone и браузера: колоды слов и диалогов, карточки, прогресс, озвучка.

Адрес: https://vishandr.github.io/deutsch/

## Установка на iPhone
1. Открыть адрес в Safari.
2. «Поделиться» → «На экран „Домой“».
3. Запускать с иконки — приложение откроется без панели браузера и будет работать без интернета.

## Структура
- `index.html`, `app.css`, `app.js` — само приложение
- `sw.js` — офлайн-режим (кэширует приложение и колоды)
- `manifest.webmanifest`, `icons/` — иконка и настройки для экрана «Домой»
- `decks/index.json` — список колод, которые приложение подгружает
- `decks/*.json` — колоды

## Как это работает
- **Загрузка колод.** При запуске (и по кнопке «Обновить с сервера») приложение читает `decks/index.json` и скачивает перечисленные там файлы. Копия колод сохраняется на устройстве, поэтому без интернета работает последняя скачанная версия.
- **Офлайн.** `sw.js` кэширует файлы приложения. Колоды всегда сначала запрашиваются из сети, а при отсутствии связи берутся из кэша.
- **Прогресс** хранится в браузере на каждом устройстве отдельно (iPhone и Mac не синхронизируются). Очистка данных сайта в настройках браузера стирает прогресс и импортированные колоды.
- **Режимы колоды.** «Список» (или «Диалог») — просмотр с возможностью скрыть перевод; «Карточки» — тренировка.

### Карточки
- «Знаю» повышает уровень карточки на 1 (максимум 5), «Ещё раз» сбрасывает его в 0 и отправляет карточку в конец круга.
- Слово считается выученным с уровня 2 — это и показывает полоска на главном экране.
- Карточки перемешиваются, но самые слабые идут первыми.
- Кнопки: `DE → RU / RU → DE` — направление; `+ фразы` — добавить фразы к словам; `Все слова / Только трудные` — только карточки с уровнем ниже 2; `Заново` — начать круг; `Озвучка` — автоозвучка.
- «Сбросить прогресс колоды» внизу — обнуляет только текущую колоду (нужно нажать дважды).

## Добавить новую колоду
### Через GitHub (для всех устройств)
1. Положить файл `decks/<имя>.json`.
2. Дописать имя файла в `decks/index.json`. **Без этого колода в приложении не появится.**
3. Закоммитить и запушить:
   ```sh
   git add decks
   git commit -m "Add <имя> deck"
   git push
   ```
4. Подождать 1–2 минуты, пока обновится GitHub Pages, и нажать в приложении «Обновить с сервера».

### Импорт файла (только на одном устройстве)
Кнопка «Импорт колоды (.json)» на главном экране. Можно выбрать файл с одной колодой или с массивом колод. Импортированную колоду можно удалить кнопкой «Удалить колоду» внизу экрана карточек.

### Важно про прогресс
- Прогресс привязан к `id` колоды: если сменить `id`, прогресс колоды обнулится.
- Прогресс слова привязан к его полю `de`: если исправить написание слова, его прогресс начнётся заново.
- Если `id` импортированной колоды совпадает с колодой с сервера, показывается импортированная.

## Озвучка
Используется встроенный синтезатор речи браузера (без интернета и внешних сервисов). Озвучивается всегда немецкий текст.

- 🔊 в правом верхнем углу карточки — прочитать слово. В режиме `RU → DE` кнопка появляется только после переворота, чтобы не подсказывать ответ.
- «Озвучка: авто» — каждое новое слово читается само (в `RU → DE` — после переворота).
- 🔊 у каждого слова, фразы и реплики в списке и диалоге.

Приложение само выбирает немецкий голос (de-DE), предпочитая улучшенные версии.

### Как установить качественный голос
Стандартный голос звучит роботизированно — лучше скачать улучшенный (бесплатно):

- **iPhone:** Настройки → Универсальный доступ → Устный контент → Голоса → Немецкий → выбрать голос с пометкой «Улучшенный» или Premium и скачать.
- **Mac:** Системные настройки → Универсальный доступ → Устный контент → Системный голос → «Управление голосами…» → Немецкий → скачать улучшенный голос.

После скачивания **полностью перезапустить браузер** (на Mac — Cmd+Q, на iPhone — закрыть приложение в переключателе). Список голосов браузер читает при запуске.

### Если звука нет или голос плохой
- iPhone: проверить, не включён ли беззвучный режим.
- Firefox на Mac подхватывает новый голос только после полного перезапуска.
- Проверить, какие немецкие голоса видит браузер, — в консоли разработчика:
  ```js
  speechSynthesis.getVoices().filter(v => v.lang.startsWith("de")).map(v => v.name + " | " + v.lang)
  ```

## Изменения в самом приложении
Если меняются `app.js`, `app.css` или `index.html`, поднять `VERSION` в `sw.js` (например, `"v2"` → `"v3"`) — иначе установленное приложение продолжит показывать старую версию из кэша. На iPhone новая версия может появиться только со второго открытия.

Проверить локально перед пушем:
```sh
python3 -m http.server 8000
```
и открыть http://localhost:8000.

## Формат колоды «слова»
```json
{"id":"a1-thema","title":"…","subtitle":"…","type":"vocab",
 "sections":[{"title":"Einkaufen","ru":"Покупки",
   "words":[{"de":"der Laden","pl":"¨-","ru":"магазин","note":"мн.ч. die Läden"}],
   "phrases":[{"de":"Ich brauche nichts.","ru":"Мне ничего не нужно."}],
   "tip":"…"}]}
```
- `id` — уникальный, латиницей; `title` — обязательно; `subtitle` — по желанию.
- `sections[].title` — название раздела (кнопка-фильтр в списке), `ru` — перевод названия.
- `words[].de` — слово; артикль `der/die/das` в начале окрашивается цветом рода. `pl` — окончание мн. ч. (`"Pl."` — слово только во мн. ч.). `note` — пояснение, показывается на обороте карточки.
- `phrases` и `tip` — по желанию.

## Формат колоды «диалог»
```json
{"id":"a1-dialog","title":"…","type":"dialog","speakers":{"V":"Verkäuferin","K":"Kunde"},
 "lines":[{"s":"V","de":"…","ru":"…"}],"notes":["…"]}
```
- `speakers` — ключ → имя; реплики последнего собеседника показываются справа.
- `lines[].s` — ключ собеседника; `notes` — заметки под диалогом (по желанию).
